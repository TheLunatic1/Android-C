# Android C (Custom OS / ROM Development)

A repository dedicated to custom Android OS modifications, SystemUI development, and stock firmware customization.

---

## 🎯 Project Goals
* Custom Dark Neo-Brutalist UI transformation for Android.
* OS-level SystemUI modifications (Control Center, Lock Screen, Status Bar).
* Custom ROM and partition-level customization.

---

## 📂 Structure
* `tools/` - Firmware extraction, unpacking, and packing utilities.
* `systemui/` - Custom SystemUI source code, layouts, and assets.
* `overlay/` - Resource and framework overlay configurations.
* `docs/` - Partition layouts, device trees, and flashing notes.
